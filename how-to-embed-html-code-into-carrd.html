Step-by-Step Guide: How to Embed HTML in Carrd

  1. Open your Carrd site editor (or start with a Blank Template at carrd.co/build?ref=F6626JYK).
  2. Click the + (Add Element) icon in the top toolbar.
  3. Select Embed from the list of elements (marked with a Pro badge).
  4. In the Embed properties panel on the left, set the Type:
    • Code: For raw HTML, inline CSS, or JavaScript snippets.
    • Form / Widget: For third-party iframe integrations.
  5. Choose the Style / Mode:
    • Inline: Renders directly where placed inside the container.
    • Hidden / Head: Inserts code into the site's <head> section (great for Google Analytics or meta tracking).
    • Hidden / Body End: Inserts code right before </body> (great for chat widgets).
  6. Paste your custom HTML snippet into the code box and click Done.
  7. Publish your site to see your live embedded widget!
